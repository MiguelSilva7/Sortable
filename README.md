# 🚀 Herodex

Herodex est une application web simple qui permet d’explorer une liste de héros et vilains avec leurs statistiques, races et autres infos.  
Les données sont récupérées depuis une API, ce qui permet d’afficher les informations dynamiquement.  
Vous pouvez rechercher,trier et naviguer facilement grâce à la pagination.

## 📂 Contenu du projet
- `main.html` → la page principale
- `main.css` → la mise en forme
- `sortable.js` → les fonctionnalités (tri, recherche, pagination, récupération depuis l’API)

## ▶️ Comment lancer le projet
1. Téléchargez ou clonez le projet sur votre ordinateur.
2. Ouvrez le fichier `main.html` :
   - soit en double-cliquant dessus
   - soit avec la commande :
     ```bash
     xdg-open main.html   # Linux
     start main.html      # Windows
     open main.html       # macOS
     ```
C’est tout 🎉 L’application s’ouvre directement dans votre navigateur et récupère les données depuis l’API.

## ✨ Fonctionnalités
- Liste de héros et vilains via l’API
- Recherche par nom
- Tri par statistiques (force, vitesse, intelligence…)
- Navigation avec pagination
